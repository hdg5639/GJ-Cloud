BEYOND A DASHBOARD

인프라 기능을 나열하지 않고,

GamjaBox는 개인 Proxmox 환경 위에서 VM 생성, 접근, 배포, 외부 공개, 협업과 운영을 끝까지 이어 주는 셀프호스팅 클라우드 플랫폼입니다.

OPERATE AS A PRODUCT

배포 다음 날에도 필요한
운영 기능까지 갖췄습니다.

서버 콘솔을 오가며 따로 처리하던 작업을 VM과 사용자 맥락 안에 모았습니다.

AUTO PREVIEW

OpenAPI를 실제 서비스형 화면으로

API와 설명을 분석해 페이지·시나리오·데이터 흐름을 조립하고, 동일한 Runtime으로 VM에 배포합니다.

  • JSON·YAML·문서 URL 입력
  • 제품형 다중 페이지·모달·Flow
DATA & CONTAINERS

Docker 운영과 DB 백업을 한곳에서

Compose 상태와 로그를 확인하고 PostgreSQL, MySQL, MongoDB, Redis 백업을 생성·보관합니다.

  • AES-256-GCM 백업 암호화
  • 체크섬·보존 기간 관리
OBSERVABILITY

자원과 서비스 상태를 이어서 확인

CPU, 메모리, 디스크와 네트워크 메트릭부터 포트, 배포 로그, 상태 변경까지 VM 단위로 살펴봅니다.

  • 실시간 상태·메트릭
  • 포트와 CNAME 라우트 관리
COLLABORATION

역할이 있는 조직 단위 운영

OWNER, ADMIN, MEMBER 역할에 따라 VM 작업을 제어하고 공지, 메모, 요청으로 운영 맥락을 공유합니다.

  • 서버 재검증 기반 권한
  • 협업 공지·메모·요청
PUBLIC ACCESS

필요한 서비스만 안전하게 공개

Cloudflare DNS, Tunnel, Access와 CNAME을 연결해 VM의 내부 서비스와 외부 도메인을 관리합니다.

  • 다중 서비스 라우팅
  • Zero Trust 접근 정책
GUIDE & SUPPORT

설명서와 문의도 포털 안에서

실제 기능에 맞는 사용 설명서를 검색하고, 필요한 도움은 문의로 남겨 관리자와 상태를 이어갑니다.

  • Docs CMS · 이미지·태그·검색
  • 사용자 문의·관리자 답변

ONE CONTINUOUS FLOW

생성에서 공개와 운영까지,
끊기지 않는 경험.

01

계획

플랜, 디스크, SSH 키를 고르고 VM 생성을 요청합니다.

02

프로비저닝

VM, cloud-init, SSH 검증과 네트워크 구성이 자동으로 진행됩니다.

03

개발·배포

터미널과 파일을 다루거나 GitHub·Auto Preview로 서비스를 배포합니다.

04

공개

포트와 CNAME을 연결하고 Cloudflare를 통해 외부에 공개합니다.

05

운영

메트릭, 로그, 백업과 조직 권한을 지속적으로 관리합니다.

REAL INFRASTRUCTURE

화면 뒤의 역할도
명확하게 나뉘어 있습니다.

Portal이 사용자 경험을 묶고 Auth, User, VM, Ops가 각자의 데이터와 책임을 소유합니다. Caddy와 Cloudflare가 진입점을 보호하고 Proxmox VE와 사용자 VM까지 실제 작업을 이어갑니다.
